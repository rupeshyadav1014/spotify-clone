# Spotify Clone

A responsive web-based music player inspired by modern music streaming platforms.

The project is built from scratch using vanilla **HTML, CSS, and JavaScript**, without any frontend framework. It focuses on creating a functional music player with a clean and responsive user interface.

The application supports local audio playback along with essential music-player features such as play/pause, next/previous track, progress control, volume management, shuffle, and repeat.

## Live Demo

[Open Spotify Clone](https://rupeshyadav1014.github.io/spotify-clone/)

The project is deployed using GitHub Pages and can be accessed directly from the browser.

## Features

### Music Playback

- Play and pause songs
- Next and previous song controls
- Automatic next-song playback
- Local MP3 audio support

### Player Controls

- Interactive progress bar
- Current playback time
- Total song duration
- Volume control
- Mute and unmute
- Shuffle mode
- Repeat mode

### User Interface

- Spotify-inspired dark theme
- Album artwork
- Current song information
- Active song indicator
- Responsive layout
- Interactive player controls

### Keyboard Controls

| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `←` | Previous Song |
| `→` | Next Song |
| `M` | Mute / Unmute |
